# CyFileTransfer

CyFileTransfer — приложение для Android TV для передачи файлов между устройствами через локальную сеть.

Приложение превращает Android-устройство в локальный файловый сервер. Для загрузки файлов с телефон, компьютера или другого устройства достаточно открыть браузер.

## Возможности

### Передача файлов
- Передача файлов через браузер.
- Подключение по локальному IP-адресу и порту 1111.
- Подключение с помощью QR-кода.
- Загрузка нескольких файлов одновременно.
- Поддержка перетаскивания файлов.
- Отображение прогресса и скорости загрузки.

### Управление файлами
- Просмотр загруженных файлов.
- Отображение имени, размера и даты.
- Скачивание файлов через браузер.
- Удаление одного или нескольких файлов.
- Подтверждение удаления.
- Открытие файлов средствами Android.
- Поддержка установки APK-файлов.

## Как это работает

1. Запустите CyFileTransfer.
2. Включите файловый сервер.
3. Получите QR-код и адрес подключения.
4. Подключите второе устройство к той же сети.
5. Откройте адрес в браузере или отсканируйте QR-код.
6. Выберите файлы и загрузите их.

## Хранение файлов

Файлы сохраняются в папке PhoneTransfer.

Путь: Android/data/com.cyfiletransfer.app/files/PhoneTransfer

## Технологии

- Kotlin
- Jetpack Compose
- Material 3
- Android SDK
- NanoHTTPD — локальный HTTP-сервер
- ZXing — генерация QR-кодов
- FileProvider — безопасная передача файлов другим приложениям

## Требования

- Android 6.0 (API 23) или новее.

## Безопасность

- Сервер работает в локальной сети.
- Авторизация по паролю не предусмотрена.
- Не рекомендуется использовать сервер в недоверенных сетях.
